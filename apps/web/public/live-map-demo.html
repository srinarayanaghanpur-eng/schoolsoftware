How this connects in the ERP
  1. Driver app posts a fix to /api/driver/location every ~10 s while a trip is active.
  2. This admin page polls /api/admin/transport/live-locations every 10 s.
  3. If the map library or tiles cannot load, the page falls back to the relative-position plot shown here.
