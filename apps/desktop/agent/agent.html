Android SMS gateway

SMS Gateway for Android: start the local server, open http://<phone-ip>:8080/docs on this PC, then enter the same local URL with /message, the app username/password and Basic auth. The nested body and phoneNumbers array are generated automatically. Keep both devices on the same Wi-Fi. This app does not use Twilio, WhatsApp Cloud API or any paid service.

Limits & safety

Recommended for 50–100/day: cap 100, delay 5000 ms, batch 20, batch pause 60000 ms. Do not run multiple campaigns at once.
