# Deferred Items Register

Items consciously deferred from a gate. An item not listed here is assumed to be
in scope. C7 cannot close while a deferrable C6 item is missing from this file.

## Rules

- Only the Product Owner may approve a deferral.
- Every deferral states the risk accepted and a target milestone.
- A deferred item that would be P0 or P1 cannot be deferred; it must be fixed.
